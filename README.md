# OpenTopography_LiDARSurveyofJohnHenryMineWA2023vs2021
A LiDAR/Point Cloud Data processing example using John Henry Mine, King County, Washington, United States of America. This project uses a PDAL workflow to analyze differences in the mine between 2021 and 2023. 2023 LiDAR uses data distributed by opentopography.com while 2021 dataeset uses data distributed by USGS 3D Elevation Program.
